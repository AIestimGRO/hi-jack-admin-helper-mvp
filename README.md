# Hi Jack Club Admin Helper

Текущая версия: **1.9**.

Отдельный мобильный сервис для администраторов Hi, Jack Club: поиск клиента, QR по телефону, преференции и полный журнал операций.

## Что входит в MVP

- аккаунты с логином/PIN, роли `admin` и `master_admin`, защищённая cookie-сессия и CSRF;
- импорт CSV (`;`, `,`, UTF-8, CP1251) и XLSX с предпросмотром и сопоставлением колонок;
- обновление клиентов по нормализованному телефону или App ID без создания дублей;
- поиск по телефону, имени, никнейму, username, App ID и Telegram ID;
- QR, содержащий строго 10 цифр `phone_local`;
- ФриЭнтри, ФриРеЭнтри, ФриАдон и процент скидки на Бар&Кальян;
- мастер-раздел для создания, переименования, сортировки и безопасного отключения преференций;
- создание администраторов, смена PIN и отдельный аудит действий мастер-админа;
- публичный мобильный квиз на `quiz.hijackpoker.ru` с вопросами по одному на экран;
- визуальный мастер-конструктор вопросов, вариантов, правильных ответов и баллов;
- единый серверный таймер на прохождение всего теста;
- кампании, параметры `referrer_id`/`source`, связка с общей клиентской базой и защита от повторов;
- автоматическое начисление настроенного бонуса с записью в общий журнал;
- праздничная анимация и персональное сообщение о выигрыше либо поддерживающий экран при недоборе баллов;
- защищённая админка результатов, статистика и CSV-экспорт;
- простой табличный список результатов с отдельной подробной страницей каждого прохождения;
- расписание активности каждой кампании с точностью до минуты и настраиваемым часовым поясом;
- атомарное начисление/списание без отрицательного баланса;
- карточка и глобальный журнал операций с CSV-экспортом;
- единый адаптивный интерфейс в фирменных цветах и с символикой Hi, Jack! на всех административных и публичных экранах;
- systemd, Nginx, HTTPS-инструкция и ежедневный бэкап за 14 дней.

## Локальный запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
cp .env.example .env
# Заполните HJC_MASTER_LOGIN, HJC_ADMIN_PIN, HJC_SECRET_KEY и публичные URL
set -a; source .env; set +a
.venv/bin/uvicorn app.main:app --reload --host 127.0.0.1 --port 8090
```

Откройте `http://127.0.0.1:8090`. Для локального HTTP поставьте `HJC_SECURE_COOKIE=false`; на VPS должно быть `true`.

Стили и JavaScript подключаются с номером версии из файла `VERSION`. После обновления браузер получает согласованный комплект интерфейса без смешивания старых скриптов с новыми страницами.

## Тесты

```bash
.venv/bin/pytest -q
```

SQLite-схема создаётся автоматически при старте. Полная инструкция VPS: [deploy.md](deploy.md).

При первом запуске создаётся мастер-аккаунт с логином `HJC_MASTER_LOGIN` и PIN из `HJC_ADMIN_PIN`. После этого аккаунты хранятся в SQLite, а изменение PIN в `.env` не перезаписывает существующий мастер-аккаунт.

## Важные правила данных

- `phone_local` — только 10 цифр, без `7`/`8`; именно эта строка помещается в QR.
- Если один телефон и App ID указывают на разные существующие карточки, импорт пропускает конфликт вместо опасного объединения.
- App ID, Telegram ID и Referrer ID сохраняются, но показаны в сворачиваемом вторичном блоке.
- Все изменения преференций проходят внутри транзакции и записываются в `preference_log`.
- Используемая преференция не удаляется: мастер может отключить её, сохранив балансы и историю.
- Обычный администратор не имеет доступа к мастер-странице и мастер-API.
- Публичный поддомен не открывает базу клиентов или админские API.

## Квиз

Публичные ссылки:

```text
https://quiz.hijackpoker.ru/
https://quiz.hijackpoker.ru/quiz?campaign=honor_more&referrer_id=485&source=tg_post
```

Файл `data/quiz_questions.json` используется только для первоначального переноса стартовых вопросов в SQLite. После первого запуска вопросы создаются и редактируются через «Мастер → Кампании квиза → Редактор вопросов». Если у активной кампании нет собственных опубликованных вопросов, используются вопросы `default`.

Поддерживаются:

- `single_choice` — один вариант; мастер может отметить один правильный ответ;
- `multi_choice` — несколько вариантов; ответ засчитывается только при полном совпадении набора;
- `text` — свободный ответ, который не участвует в автоматическом подсчёте.

Вопрос заполняется вместе со всеми вариантами и сохраняется одной кнопкой — отдельные действия для черновика и публикации не нужны. Сохранённый вопрос сразу участвует в квизе. Для вопроса с выбором нужно добавить минимум два варианта и отметить правильные ответы. Каждому проверяемому вопросу назначаются баллы. В настройках кампании указываются проходной порог, бонусная преференция, количество бонусов и общее число секунд на прохождение теста. Нулевой лимит полностью отключает таймер. Порог `0` означает бонус за сам факт прохождения и сохраняет старое поведение.

Основной редактор сохраняет текст вопроса, все варианты и правильные ответы одной кнопкой. Для изменения достаточно раскрыть нужный вопрос в списке, отредактировать его и нажать «Сохранить изменения». Поля баллов и обязательности находятся в «Дополнительных настройках», а перемещение, дублирование и удаление — в скрытом меню второстепенных действий.

Для массового добавления откройте «Добавить несколько вопросов текстом». Первая строка блока — вопрос, строки со `*` — правильные ответы, строки с `-` — неправильные. Между вопросами нужна пустая строка:

```text
Какая комбинация старше?
- Стрит
* Флеш
- Тройка

Выберите красные масти
* Червы
* Бубны
- Пики
```

Одна звёздочка создаёт вопрос с одиночным выбором, несколько звёздочек — с множественным. Импорт выполняется целиком: при ошибке в одном блоке ни один вопрос из вставки не сохраняется.

После старта сервер фиксирует единый дедлайн всей попытки. Участник переходит между вопросами кнопками «Назад» и «Далее» и может изменить предыдущий ответ; каждое изменение сохраняется на сервере. Когда общее время заканчивается, тест автоматически завершается, а неотвеченные вопросы считаются неверными. Подмена времени на устройстве не продлевает серверный дедлайн.

Для каждого результата сохраняются баллы, количество правильных ответов, достижение порога и снимок текста вопросов/вариантов на момент прохождения. Поэтому дальнейшее редактирование квиза не изменяет старые результаты. Правильные ответы никогда не передаются публичному API. При достижении порога участник видит конфетти и сообщение с названием назначенного бонуса; при недоборе — сообщение «Не расстраивайтесь — в следующий раз вам обязательно повезёт!».

Результаты доступны всем авторизованным администраторам на `/admin/quiz-results`.

Общий экран результатов показывает только телефон, username, баллы, прохождение порога, состояние бонуса, дату и название квиза. Клик по строке открывает отдельную страницу со всеми данными и ответами участника.

В настройках кампании поля «Активен с» и «Активен до» задают период приёма новых прохождений. Оба поля необязательны. Часовой пояс берётся из `HJC_TIMEZONE` (по умолчанию `Europe/Moscow`). До начала участник увидит время старта, после окончания — сообщение о завершении квиза. Уже начатая в разрешённый период попытка может быть закончена.

Антиспам включает скрытое honeypot-поле, лимит отправок по HMAC-хэшу IP и отметку повторного прохождения одной кампании. Исходный IP в базе не хранится. Повторный ответ сохраняется для аналитики, но второй автоматический бонус не начисляется.
